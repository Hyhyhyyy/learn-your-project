# 学习你的项目 · Learn Your Project

面向 VIBE CODING 时代的**纯静态**项目学习助手。无后端、零依赖运行时：配置任意 OpenAI 兼容大模型 API，粘贴 GitHub 仓库地址，一键生成专业评估报告与零基础图文教学，并以项目本身为知识库做精准问答。

> 密钥仅存于浏览器本地，不会上传到任何服务器。

## 特性

- 🔌 **任意 OpenAI 兼容模型**：阿里云百炼 / DeepSeek / Moonshot / 智谱 / 混元 / Ollama / OpenAI 等（需允许浏览器跨域 CORS，百炼、DeepSeek、Moonshot 等均原生支持）。
- 🌱 **纯浏览器加载 GitHub 仓库**：经 GitHub API 在前端直接拉取，目录深的大仓库自动 BFS 分页，避免 504。
- 📊 **一键评估报告** + 📚 **一键零基础教学**（含 Mermaid 图解、GitHub/官网/B 站权威资源外链）。
- 💬 **基于项目的问答**：TF-IDF 分块检索（含中文 `Intl.Segmenter` 分词）+ LLM 作答，引用真实文件路径。
- 🎨 自然有机风（暖奶油 / 鼠尾草 / 琥珀），模块卡片化输出，链接三态区分（未点击 / 可点击 / 点击过）。
- 🔄 **加载门控**：项目未完全载入前禁用生成与问答按钮，全程转圈提示阶段进度。

## 使用

直接打开 [GitHub Pages 站点](https://hyhyhyyy.github.io/learn-your-project/) 即可：

1. 「模型配置」填写 API Key / 基地址 / 模型 → 点击「验证配置」。
2. 「加载仓库」粘贴 `https://github.com/owner/repo` → 点击「加载仓库」。
3. 「学习空间」生成报告 / 教学，或在「项目问答」提问。

## 本地预览

任意静态服务器均可，例如：

```bash
npx serve .          # 或
python -m http.server 8000
```

## 说明

- 浏览器会自动使用系统代理，无需单独配置。
- 教学中的外链由大模型依据项目技术栈生成，使用前请自行核实链接有效性。
