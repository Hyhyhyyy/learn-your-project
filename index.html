① 配置大模型 API

支持 OpenAI 兼容接口，也支持 Anthropic Claude / Google Gemini 原生 API（需允许浏览器跨域 CORS）。密钥仅存于本机浏览器，不会上传到任何服务器。

⚠️ OpenAI 兼容：结尾通常要带 /v1（例如 Ollama 应为 http://localhost:11434/v1，只填 http://localhost:11434 会 404）。

💡 浏览器会自动使用你的系统代理，无需单独配置。例如百炼：基地址 https://dashscope.aliyuncs.com/compatible-mode/v1，模型 qwen-plus。模型栏为候选建议，可下拉选择也可直接手填任意模型名。

🔎 检索设置（影响「项目问答」质量）
问答前用 LLM 改写查询（中文更准）

向量检索：用你配置的 Embedding 端点计算向量，浏览器本地做余弦相似度，无后端。开启后会按块调用 Embedding（消耗 token，已抓取文件越多越慢），问答更懂代码语义。

⚙️ Embedding 专用端点（可选 · 用于兑现「另配 Embedding」）

主风格为 Claude（原生不支持 Embedding）时，在此填一个 OpenAI 兼容的 Embedding 端点（如 OpenAI / Voyage / 本地 bge）即可启用向量检索；Gemini 可直接用同一端点。三者留空则沿用主端点。
